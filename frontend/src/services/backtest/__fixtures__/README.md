# Backtest fixtures — provenance

These JSON files are the **frozen oracle** for
`frontend/src/services/backtest/backtestEngine.ts` (asserted by
`src/__tests__/services/backtestEngine.test.ts`).

They were generated by `python/tests/gen_backtest_fixtures.py`, which ran the real
`python/cli/backtest.py` over a fixed parameter matrix and dumped its stdout
value-for-value. Both scripts were **removed on 2026-09-29** together with the rest of
the Python backtest path (Node route + PythonRunner wrapper), after the port had been
verified:

* 12/12 engine cases value-identical (these files),
* 400+ randomly generated cases value-identical (`python/tests/differential_backtest.py`,
  0 mismatches in the ported domain: monthly/weekly/lump_sum with `amount > 0`),
* `pyround.json` / `isoweek.json` captured straight from CPython
  (`round()`, `datetime.isocalendar()`).

**Do not hand-edit.** If the engine behaviour changes on purpose, regenerate by adding a
short script that re-emits these shapes (or adjust the affected expectations knowingly) —
the point of the files is to stay byte-stable so that any accidental drift fails CI.

| File | Contents |
|------|----------|
| `engine.json` | 12 backtest scenarios: monthly/weekly/daily/lump_sum, initial amount, fees, take-profit/stop-loss exits, rounding ties, cross-year weeks, single point, empty input |
| `pyround.json` | 104 cases of CPython `round(value, digits)` (banker's rounding, tie and precision traps) |
| `isoweek.json` | 28 dates with the ISO year/week/weekday from `datetime.isocalendar()` |
