# 4433 法则

## 一、概念

4433 法则是基金筛选中的一种经典定量规则，通过四个维度对基金进行筛选，要求基金在不同时间区间的同类排名均处于前列。

## 二、判定规则

`frontend/src/composables/useScreeningDb.ts:308` `check4433Rule()`：

```
条件 A: 近1年同类排名前 25%      (rank_pct_1y ≤ 25)
条件 B: 近2年 或 近3年排名前 25%  (rank_pct_2y ≤ 25 或 rank_pct_3y ≤ 25)
条件 C: 近6月同类排名前 33.33%    (rank_pct_6m ≤ 33.33)
条件 D: 近3月同类排名前 33.33%    (rank_pct_3m ≤ 33.33)
```

全部满足则 `pass_4433 = 1`，否则为 `0`。

```typescript
function check4433Rule(ranks): boolean {
  if (ranks.rank_pct_1y == null || ranks.rank_pct_1y > 25) return false
  const longTermPass = (ranks.rank_pct_2y != null && ranks.rank_pct_2y ≤ 25) ||
    (ranks.rank_pct_3y != null && ranks.rank_pct_3y ≤ 25)
  if (!longTermPass) return false
  if (ranks.rank_pct_6m == null || ranks.rank_pct_6m > 33.33) return false
  if (ranks.rank_pct_3m == null || ranks.rank_pct_3m > 33.33) return false
  return true
}
```

## 三、计算过程

`useScreeningDb.ts:111` `compute4433()`：

```
1. 读取 IndexedDB 全部 screeningFunds
2. 按 fund_type 分组
3. 每组 >= 3 只时才计算（不足则全部设为 null）
4. 对每组内每只基金，按各区间收益率排序
5. 排名百分位 = (i / total) × 100，i 从 0 开始
6. 按 check4433Rule 判定 → pass_4433
7. bulkPut 写回 IndexedDB
```

### 示例

以"股票型"组为例，共 100 只基金：

| 1 | 基金A | +35.2% | 0% | +8.1% | 0% | +18.5% | 0% | 1 |

| 34 | 基金D | +18.5% | 33% | +4.8% | 33% | +10.2% | 33% | 0 ✗(rank_pct_6m > 33.33) |

## 四、后端服务端 4433 排名

`service/src/services/chatIndustryTools.ts:161` `compute4433Ranking()` 是后端版本的实现，供 AI 对话工具调用：

- 从 `FundScreeningSnapshotItemDto[]` 输入
- 按 `classifyFundType(name)` 分组（不同于前端的 fund_type 字段）
- 近1年 p75 分位数 ≥ 近2年/p75 + 近3年/p75（至少满足一个）
- 近3月/6月 p66.7 分位数（即前 1/3）
- 返回符合条件的前 50 只，按近1年收益降序
- 返回字段：`fund_code, fund_name, fund_type, return_1y, return_3m, return_6m`

两种实现的差异：

| 维度 | 前端 check4433Rule | 后端 compute4433Ranking |
|------|-------------------|------------------------|
| 分组依据 | `fund_type` (后端提供) | `classifyFundType(name)` (名称解析) |
| 排名指标 | 百分位 (0~100) | 分位数阈值比较 |
| 适用场景 | 筛选页 4433 筛选 | AI 聊天工具调用 |
| 缓存 | IndexedDB | 无（实时计算） |

## 五、筛选页中的使用

- 高级筛选 → 同类排名 → "4433法则" 复选框
- 勾选后筛选条件 `filters.pass_4433 = true`
- `queryFunds()` 时直接走 IndexedDB 索引 `db.screeningFunds.where('pass_4433').equals(1)`
- 结果表格中 `pass_4433` 列显示绿色勾 ✓
