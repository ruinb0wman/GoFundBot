## 1. 安全加固

| 序号 | 问题 | 说明 | 建议方案 |
|------|------|------|----------|
| 1.1 | 无速率限制 | 全栈 (Flask / DataService) 所有 API 均无限流，可被滥用 | Flask-Limiter 中间件；DataService express-rate-limit |
| 1.2 | 无输入校验框架 | 仅 `assertCode()` 做基础校验，无请求体验证 | marshmallow / pydantic 做请求模型校验 |
| 1.3 | `.env` 密钥已提交到仓库 | LLM / 搜索 API 密钥明文存在于 repo 内 | `.gitignore` 排除 `.env`；仅保留 `.env.example` 不含真实密钥 |
| 1.4 | CORS 默认全放行 | Backend `flask-cors` 和 DataService `cors` 均未限制来源 | 生产环境配置白名单 |
| 1.5 | 无 CSRF 防护 | POST/PUT/DELETE 端点无 token 校验 | Flask-WTF CSRF 或无状态 API 方案 (SameSite Cookie) |

## 3. 性能优化

| 序号 | 问题 | 说明 | 建议方案 |
|------|------|------|----------|
| 3.1 | 无前端状态管理 | 组件各自独立调 API，重复请求（如 `FundWatchlist` 和 `FundSearch` 各自 fetch） | 引入 Pinia；共享状态避免重复请求 |
| 3.2 | 无 HTTP 缓存头 | Flask 响应无 `ETag` / `Cache-Control` / `Last-Modified` | 按资源类型设置合理 TTL |
| 3.3 | 图表无节流重渲染 | `FundDetail` / `MarketOverview` 每次数据更新都重绘 ECharts | `requestAnimationFrame` 或 `debounce` 合并渲染 |
| 3.4 | 前端无骨架屏 | 加载状态仅为简单 spinner | Vue Suspense + skeleton 组件 |
| 3.5 | 生产环境无 Gzip/Brotli | 静态资源未压缩传输 | Nginx 反向代理压缩；或 Flask-Compress |
| 3.6 | SQLite 单写入者瓶颈 | 批量筛选更新时写锁阻塞 | WAL 模式 (`PRAGMA journal_mode=WAL`)；考虑超时重试 |
| 3.7 | DataService 内存缓存上限 2000 条 | LRU 淘汰可能丢弃有价值数据 | 增大上限或对长 TTL 数据做文件持久化 |
| 3.8 | 部分端点无分页 | `/api/watchlist` 返回全量 | 统一增加 `page`/`page_size` 参数 |
