## Phase 1 — 低风险基础设施（P0，并行推进）

### 节点 1.1：SQLite WAL 模式

| 步骤 | 文件 | 操作 |
|------|------|------|
| 1.1a | `Scripts/database.py` | `engine = create_engine(...)` 后，通过事件监听器在连接时执行 `PRAGMA journal_mode=WAL` |

```python
# database.py — engine 创建后添加
from sqlalchemy import event

@event.listens_for(engine, "connect")
def _set_sqlite_pragma(dbapi_connection, connection_record):
    cursor = dbapi_connection.cursor()
    cursor.execute("PRAGMA journal_mode=WAL")
    cursor.execute("PRAGMA busy_timeout=5000")
    cursor.close()
```

### 节点 1.2：HTTP 缓存头

| 步骤 | 文件 | 操作 |
|------|------|------|
| 1.2a | `Scripts/app.py` 或新建 `Scripts/core/cache_headers.py` | `@app.after_request` 中间件，按路径模式设置 `Cache-Control` |
| 1.2b | 同上 | 为 Service 代理路由设置适当的缓存 TTL |

**缓存策略**：
```
/api/fund/<code>              → private, max-age=60     (基金详情，60s 客户端缓存)
/api/watchlist                → private, max-age=0      (自选列表，不缓存)
/api/market/overview          → public, max-age=30      (市场概览，30s)
/api/market/news              → public, max-age=60      (快讯，60s)
/api/v1/fund/<code>           → private, max-age=60     (v1 基金详情)
/static/* (JS/CSS/图片)       → public, max-age=31536000, immutable (静态资源，1年)
```

```python
# core/cache_headers.py（新建）
from flask import request

CACHE_RULES = [
    ('/static/', 'public, max-age=31536000, immutable'),
    ('/api/market/', 'public, max-age=30'),
    ('/api/fund/', 'private, max-age=60'),
    ('/api/v1/fund/', 'private, max-age=60'),
    ('/api/watchlist', 'private, max-age=0, no-store'),
    ('/api/screening/', 'private, max-age=60'),
]

def apply_cache_headers(response):
    if request.method != 'GET':
        return response
    path = request.path
    for prefix, header_value in CACHE_RULES:
        if path.startswith(prefix):
            response.headers['Cache-Control'] = header_value
            break
    return response
```

**验收点**：
- [ ] `curl -I localhost:5000/api/fund/000001` 返回 `Cache-Control: private, max-age=60`
- [ ] `curl -I localhost:5000/api/watchlist` 返回 `Cache-Control: private, max-age=0`
- [ ] `curl -I localhost:5000/static/index.html` 返回 `Cache-Control: public, max-age=31536000`

### 节点 2.2：fundStore — 消除重复基金详情请求

| 步骤 | 文件 | 操作 |
|------|------|------|
| 2.2a | `Frontend/src/stores/fundStore.js`（新建） | `defineStore('fund', ...)`：`fundCache: Map`, `fetchFund(fundCode)` 去重 |
| 2.2b | `Frontend/src/components/FundDetail.vue` | 替换 `fundAPI.getFundDetail()` 为 `fundStore.fetchFund()` |
| 2.2c | `Frontend/src/components/FundBasicInfo.vue` | 同上（此组件由 FundDetail 内嵌渲染，直接使用 shared state） |
| 2.2d | `Frontend/src/components/FundRealtime.vue` | 同上 |
| 2.2e | `Frontend/src/components/MyPositions.vue` | 同上，替换独立 fetch |

```js
// stores/fundStore.js
import { defineStore } from 'pinia'
import { fundAPI } from '../services/api'

export const useFundStore = defineStore('fund', {
  state: () => ({
    cache: {},
    pendingRequests: {},
  }),
  actions: {
    async fetchFund(fundCode, force = false) {
      const cached = this.cache[fundCode]
      if (!force && cached && Date.now() - cached.ts < 60000) {
        return cached.data
      }
      if (this.pendingRequests[fundCode]) {
        return this.pendingRequests[fundCode]
      }
      const promise = fundAPI.getFundDetail(fundCode).then(res => {
        delete this.pendingRequests[fundCode]
        this.cache[fundCode] = { data: res.data, ts: Date.now() }
        return res.data
      }).catch(err => {
        delete this.pendingRequests[fundCode]
        throw err
      })
      this.pendingRequests[fundCode] = promise
      return promise
    },
    clearCache() {
      this.cache = {}
    }
  }
})
```

**验收点**：
- [ ] 打开基金详情页，浏览器 Network 面板显示 `GET /api/fund/<code>` 仅 1 次（而非 FundDetail + FundBasicInfo 各 1 次）
- [ ] 60s 内再次访问同一基金，无额外网络请求（复用缓存）
- [ ] 同一基金被多个组件同时请求时，只有 1 个实际网络调用

```js
// composables/useDebouncedWatch.js
import { watch } from 'vue'

export function useDebouncedWatch(source, callback, wait = 300, options = {}) {
  let timer = null
  watch(source, (...args) => {
    if (timer) clearTimeout(timer)
    timer = setTimeout(() => {
      timer = null
      callback(...args)
    }, wait)
  }, { ...options, flush: 'pre' })
}
```

**验收点**：
