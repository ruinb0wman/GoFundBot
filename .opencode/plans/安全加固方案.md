```python
# Scripts/core/logging.py (new)
import logging
import json
import sys
from datetime import datetime

class JsonFormatter(logging.Formatter):
    def format(self, record):
        return json.dumps({
            "time": datetime.utcnow().isoformat() + "Z",
            "level": record.levelname,
            "logger": record.name,
            "message": record.getMessage(),
            "module": record.module,
            "func": record.funcName,
            "line": record.lineno,
        }, ensure_ascii=False)

def init_logging(level=logging.INFO):
    handler = logging.StreamHandler(sys.stdout)
    handler.setFormatter(JsonFormatter())
    root = logging.getLogger()
    root.handlers.clear()
    root.addHandler(handler)
    root.setLevel(level)
```

## Phase 1 — 速率限制（P0，阻断滥用）

区分读写操作限流，保护后端和第三方 API。

### 节点 1.1：Flask 速率限制

| 步骤 | 内容 | 实施方案 |
|------|------|----------|
| 1.1a | 安装 Flask-Limiter | `pip install Flask-Limiter`；添加到 `requirements.txt` |
| 1.1b | 配置全局默认限流 | `app.py` 中初始化 |
| 1.1c | 写操作严限 | `POST/PUT/DELETE` → `30/hour` |
| 1.1d | AI 端点严限 | `/api/fund/<code>/analyze`、`/api/market/daily` → `10/hour` |
| 1.1e | 后台任务豁免 | `/api/screening/update` → 内网/豁免 |
| 1.1f | 存储 | 初期 `memory://`，多进程切 `redis://` |

**代码变更**：
- `Scripts/requirements.txt`: `Flask-Limiter>=3.5`
- `Scripts/app.py:28-29`:
  ```python
  from flask_limiter import Limiter
  from flask_limiter.util import get_remote_address
  limiter = Limiter(app, key_func=get_remote_address, default_limits=["200/day", "50/hour"])
  ```
- `app.py:140+` AI 分析路由添加装饰器：
  ```python
  @app.route('/api/fund/<fund_code>/analyze')
  @limiter.limit("10/hour")
  def analyze_fund(fund_code): ...
  ```
- `fund_master_routes.py` / `data_service_routes.py` 写操作端点添加 `@limiter.limit("30/hour")`

### 节点 1.2：Service 速率限制

| 步骤 | 内容 | 实施方案 |
|------|------|----------|
| 1.2a | 安装 express-rate-limit | `npm install express-rate-limit` |
| 1.2b | 全局限制 | `15 min` 窗口内 `max: 300` |
| 1.2c | 路由级覆盖 | `/api/funds/estimates` 更严格；`/api/news/flash` 更高上限 |

**代码变更**：
- `Service/package.json`: `"express-rate-limit": "^7.0"`
- `Service/src/app.ts`:
  ```typescript
  import rateLimit from 'express-rate-limit';
  const globalLimiter = rateLimit({ windowMs: 15 * 60 * 1000, max: 300 });
  app.use(globalLimiter);
  ```

## Phase 5 — CSRF 保护（P2）

> 当前无用户认证体系，CSRF 攻击实际危害有限。本阶段应在引入认证体系时同步完成。

| 节点 | 方案 | 说明 |
|------|------|------|
| **5.1** 方案评估 | Double Submit Cookie + SameSite=Strict（推荐） | SPA + API 架构下无状态方案 |
| **5.2** Flask 实现 | Flask-WTF CSRF 中间件 | 所有 POST/PUT/DELETE 自动校验 |
| **5.3** 前端适配 | axios interceptor | 从 cookie 提取 token 注入 `X-CSRF-Token` header |
